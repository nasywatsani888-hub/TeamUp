FOLDER POSTER LOMBA
===================
Taruh gambar poster lomba di folder ini. Aplikasi memakainya di:
  - kartu lomba di Beranda,
  - kartu lomba di halaman Lomba,
  - halaman Detail Lomba.

Format file bebas: png, jpg, jpeg, atau webp. Huruf besar/kecil tidak masalah.
Nama file (TANPA ekstensi) yang dikenali aplikasi:

  Code & Create: Robotics      robotics   atau  robotik
  Lomba UI/UX Nasional         uiux       atau  informatic / informatik
  Lomba Essay Kesehatan        essay
  Byteon Coding Championship   byteon
  Hackathon Competition        zephyr     atau  zackhaton / zakhaton / hackathon

Contoh yang valid: robotik.png, informatic.jpg, Essay.JPEG, zackhaton.png
Kalau satu lomba tidak punya file, kartunya otomatis tampil sebagai blok warna + judul (tidak error).

Menambah nama baru: edit dictionary _POSTER di data_store.py.

Tips ekspor dari Figma
  - Pilih layer gambar poster -> panel Export -> PNG atau JPG -> skala 2x.
  - Lebar minimal 460 px (kartu tampil 230 px; 2x agar tajam di layar Retina).
  - Gambar dipotong otomatis agar pas (cover-crop), jadi rasio bebas; bagian tengah paling aman.
  - Jaga ukuran file kecil (idealnya < 500 KB per gambar) supaya hemat RAM.
